# 清理无效做种 v2.1 审查与 V3 优化

审查基线：`plugins.v2/cleaninvalidseed/__init__.py`，已在 MP 3.1.6 运行实例核对为 v2.1。新实现位于 `plugins.v3/cleaninvalidseed`，版本 3.0.1。

## 主要问题

| 级别 | 旧版位置 | 问题与后果 | V3 处理 |
| --- | --- | --- | --- |
| P0 | `get_all_torrents`、`detect_invalid_files` | 查询失败返回空列表，与“没有任务”混为一谈；仍会继续找无引用源文件并允许直接删除 | 查询不完整立即中断，不清理、不累计观察 |
| P0 | `service_info`、`detect_invalid_files` | 只核对选中的下载器；QB 与 TR 共用目录时，漏掉未选下载器的引用 | 失效任务与源文件保护分别确定范围；源文件核对全部配置的下载器 |
| P0 | `detect_invalid_files` | 使用字符串 `replace` 和单向子串比较；无法保护内容路径的祖先引用，且 TR 使用原始 torrent.name，重命名后可能误判 | 严格映射、路径边界、祖先和后代保护、TR 实际文件清单；路径不明则中断 |
| P0 | `detect_invalid_files` | `unlink/rmtree` 直接永久删除，无持久执行计划、无恢复机制、无执行前再次核对 | 定时只检测；人工确认后在同一文件系统移入回收区，记录意图并支持恢复 |
| P1 | `clean_invalid_seed` 第一轮 | 把状态 3“更新中”及任意“不匹配删种文本”的 Tracker 计入正常站点；故障也能成为同站点成功证据 | 只有明确 announce 成功才作为正常佐证；所有有效 Tracker 都要符合完整删种错误 |
| P1 | `clean_invalid_seed`、自定义错误 | 账号禁用、无法连接等自定义规则可以参与删除；无持续观察和批次限制 | 拒绝网络、账号、权限类规则；独立观察次数、时长及批次上限 |
| P1 | `get_torrent_hash`、`get_tracker_info` | TR camelCase/snake_case 混用，依赖合成 Tracker 条目和多层回退，可能漏检；正常状态的推断不一致 | 直接使用当前 MP / transmission-rpc 的字段契约，一次批量查询；未知状态保留 |
| P1 | `clean_invalid_seed` | 不检查 `delete_torrents` 的布尔返回值；调用后就计为已删除 | 必须操作返回成功且回读任务确实不存在；标记也回读标签 |
| P1 | `handle_commands`、定时服务 | 聊天命令暂时修改实例开关，无 `finally`，与定时任务并发会串状态；只检测时也可能受“仅标记”开关影响 | 不修改共享运行开关；捕获本轮配置，读检测始终只读；线程锁、进程文件锁及停止事件 |
| P1 | `is_file_old_enough`、`clean_invalid_seed` | “最小做种天数”只检查源文件 mtime，不保护任务；历史文件时间也不能代表实际做种时长 | 任务使用真实累计做种秒数；源文件独立静置条件，检查所有后代修改和元数据变化 |
| P2 | `safe_getattr`、`safe_hasattr` | 每个本地属性访问创建守护线程；超时后线程仍继续运行，数千任务会放大开销 | 已获取 RPC 记录直接取值，不为本地属性创建线程 |
| P2 | `clean_invalid_seed` 末尾 | 在每个下载器循环内再次扫描全部源目录，重复 IO、通知和潜在删除 | 每轮统一快照，一次源文件检测 |
| P2 | `get_form`、`get_page` | 多个删除和标记开关组合不直观；数据页为空，没有原因、选中确认、历史和恢复 | 原生共享 Vue 工作台及设置页；搜索、筛选、分页、证据展开、明确操作模式与回收区 |

## 验证边界

自动测试覆盖已确认的故障触发条件：不可用下载器、禁用下载器、清单未知、假成功返回、多 Tracker 证据、TR 字段和百分比、重新添加同 hash 任务、观察间隔、配置变更、过期计划、共享祖先目录、路径前缀冲突、目录新文件、软链接、回收区替换、恢复时同名冲突，以及工作台确认交互。

操作会重新读取任务并验证源文件指纹，但下载器和文件系统之间没有共享事务锁。源文件移动因此设计为可恢复，不提供永久删除。仅凭清理前后任务数量相同不足以证明未影响用户任务；上线验收需要比较原有任务身份、路径、分类/标签、TR 选件及全局设置摘要。

## 兼容与发布

新实现仅在 V3 市场索引登记，旧代目录保持不变。默认只预览，保留旧周期和规则；旧删除开关不自动启用。发布门禁校验索引版本、源码、联邦样式、测试、构建复现及标准插件 ZIP。
