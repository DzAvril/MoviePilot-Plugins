# 音乐歌单同步

<img src="https://raw.githubusercontent.com/DzAvril/MoviePilot-Plugins/main/icons/MusicPlaylistSync-1.7.1.png" width="96" alt="音乐歌单同步图标">

MoviePilot V3 插件，持续同步多个 **QQ 音乐、网易云音乐公开歌单**。为新增歌曲创建原生单曲订阅并立即发起搜索，下载与整理仍由 MP 完成。

当前版本 **1.9.0**，支持 MoviePilot **3.1.6**。沿用插件 ID `QQMusicPlaylistSync`，旧版配置、订阅、账本和选曲记录可继续使用。

## 功能

- 歌单卡片显示 QQ 与网易云的真实歌单封面，随歌单同步更新，通过 MP 图片缓存加载；封面不可用时回退占位图。

- QQ 完整分页；网易云先取完整歌曲 ID，再按每批最多 200 首补齐详情，避免只导入网页预览部分。
- 支持多个歌单、QQ 官方短分享链接、网易云桌面与移动端链接；不同歌单读取失败时分别保留上次完整快照。
- 同平台按歌曲身份去重。跨平台只有在歌名、全部歌手、专辑、已知年份一致、时长相差不超过 2 秒且候选唯一时合并，同名不同版本独立保留。
- 本地音乐库已有歌曲跳过；原生订阅与完成历史参与去重，重启后不重复创建。
- 建好订阅立即提交 MP 原生手动搜索队列；后续新增优先处理。仍服从站点预算、冷却和订阅过滤。
- 始终保持 `recording` 单曲身份。分轨专辑**完整下载做种，仅歌单歌曲入库**；含 CUE、仅有曲序、缺曲、版本歧义、无法验证文件清单的资源跳过。
- qB 任务暂停添加 → 核对全部文件 → 全选下载 → 回读优先级 → 仅将歌单音轨登记到 MP 整理清单 → 启动。任何选择或回读失败都保持暂停；逐文件整理拦截继续阻止其余歌曲进入音乐库。
- 音乐目录需使用硬链接或复制整理，做种源文件不移动。当前 MP 的标签写入在需要修改硬链接时生成独立副本，保留下载原件。
- 可设置未入库歌曲保留天数，默认 **0：不自动清理**。整专下载、歌单音轨全部成功入库后开始计时，保留时间与之后累计做种时长都达到设定天数才清理；暂停时间会延后清理。
- 歌曲状态显示待搜索、下载中、待入库、已入库；依据实际音轨进度与成功整理结果，每 15 秒更新。
- 状态页复用 10 分钟的本地音乐目录索引，标签缓存最多 20,000 个文件；已知入库文件是否删除、MP 整理结果和下载进度仍随页面刷新核对。
- 每天清理已闲置 90 天的插件历史，当前歌单、活动订阅、仍在下载或做种的任务及选曲保护记录继续保留。

公开歌单无需 Cookie。插件只读取音乐平台公开元数据，音频通过 MP 已配置站点获取。私密或要求登录的歌单暂不支持；没有匹配资源的歌曲保留订阅等待。

## 安装与配置

1. 在 MP 插件市场仓库设置中加入 `https://github.com/DzAvril/MoviePilot-Plugins`。
2. 刷新市场，安装 **音乐歌单同步**；V3 索引为仓库根 `package.v3.json`，联邦资源通过对应版本 Release 分发。
3. QQ、网易云分别填写在对应栏中，每行一个链接或数字 ID。网易云支持 `https://music.163.com/#/my/m/music/playlist?id=...`。
4. 开启持续同步，可先用“只预览歌单”核对总数，再关闭预览以创建订阅。

下载器、下载目录、音乐库目录 **留空时跟随 MP 音乐设置**，填写时仅覆盖对应字段。分轨选曲目前需要 qBittorrent。插件不会代替用户设置存储目录。

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 持续同步 | 关闭 | 启用后按间隔检查全部歌单 |
| 只预览歌单 | 开启 | 读取歌单，不创建订阅 |
| 同步间隔 | 60 分钟 | 1–1440 分钟；升级保留已保存的间隔 |
| 同时创建订阅数 | 4 | 1–8 路，有界并行 |
| 建好订阅立即搜索 | 开启 | 使用原生手动搜索队列 |
| 下载器、下载与音乐库目录 | 留空 | 跟随 MP 设置 |
| 未入库歌曲保留天数 | 0，不自动清理 | 0–3650 天；请按 PT 站点做种要求设置 |

## 完整做种与清理

下载清单与入库清单分别保存。例如专辑有 10 首，歌单需要 4 首：qB 下载全部文件，MP 原生下载历史与整理白名单只登记这 4 首，其余 6 首留在下载目录参与做种。以后歌单增加同专辑歌曲，可以复用缓存并经原生订阅流程补充入库。旧版部分下载任务在下一次正常同步或手动下载维护时核验归属、目录和文件清单后补全；用户手动暂停的任务保持暂停。原有 60 分钟同步设置不变。

启用清理后，只有所有计划入库歌曲均有对应成功整理记录、且当前本地音乐库文件仍存在，才开始计时。达到期限及累计做种时长后，先暂停并再次确认完整下载，移除下载器任务时**不删除数据**，回读确认任务消失，再逐个删除种子清单中未入库的音频。音乐库、已入库歌曲的下载源文件、封面等附件均保留；不递归删除目录。若其他 qB 任务仍使用该目录、文件发生替换、出现符号链接或状态读取失败，保留文件并在下次同步重试。删除进度持久化，重启后可恢复。已手动移除的任务不会被自动视为清理授权。

清理会结束该种子的做种，保留天数需满足所用站点规则。计时开始后增加新歌单歌曲会重新核对入库条件。关闭预览、启用持续同步时才执行下载维护；数据页面刷新只读状态，不触发清理。到期检查随正常歌单同步进行，时间可能晚于页面显示的最早清理时间。暂时无法验证的远程音乐库不执行文件清理。

## 兼容性与数据

注册 `qqmusic` 与 `netease` 单曲来源，不伪造 MusicBrainz 身份。QQ MID 与网易云数字 ID 保持原生身份，内部加来源前缀避免撞号。

账本通过 MP 插件数据接口持久化；完整快照才更新成员关系。移出歌单不会删除已有文件或取消原订阅。跨平台首次导入前保留 `state_before_netease_v1` 备份。

数据页每 15 秒核对下载及入库状态，目录完整遍历最多每 10 分钟进行一次；切换目录或增加尚未索引的歌名时提前重建。通过 MP 成功整理的歌曲立即参与状态判定，手动复制进目录的音乐最多在 10 分钟后的下一次页面刷新被识别。标签缓存有固定容量，目录索引仅保留歌单涉及的歌名。页面关闭后不进行状态轮询。

历史清理在正常同步时检查，每天最多一次。歌曲离开所有已配置歌单后开始计算 90 天；读取失败保留成员，不计为移除，旧版闲置记录从升级后首次同步开始计算。超过期限后，只有不再关联活动订阅及选曲保护的歌曲、对应身份别名和停用歌单可清理。选曲任务记录只有在下载器明确确认任务不存在、原下载目录或文件已不存在、全部所选音轨均有成功整理记录且入库文件可确认时才清理；读取状态失败会保留记录重试。保留中的保护记录可能超过 90 天。

上述 90 天历史清理仅作用于插件账本，不删除音乐文件、原生订阅、下载或整理历史，也不删除迁移备份；它与可选的未入库音频清理独立。已入库文件后来被手动删除时，页面会重新核对状态，插件仍不自动重新创建订阅或下载。

当前 MP 3.1.6 下载合同没有单独的下载/入库文件清单字段，因此 `selected.py` 在已验证的关键词、候选匹配和下载提交边界做窄范围内存适配。只处理本插件追踪的单曲，停止时恢复原函数，重载不叠加；宿主签名不兼容时阻止本插件提交。升级主程序后应重新检查适配器状态和音乐标签写入保护。

插件 Python 依赖均由当前 MP 音乐运行环境提供，无额外安装清单。普通数据接口使用 MP API 认证；图片和联邦文件沿用 MP 静态资源访问检查。

## 开发验证

按[官方 V3 开发指南](https://github.com/jxxghp/MoviePilot-Plugins/blob/main/docs/Plugin_Development.md)与[发布指南](https://github.com/jxxghp/MoviePilot-Plugins/blob/main/docs/Repository_Guide.md)组织源码、元数据、图标和测试。

```sh
python -m compileall -q plugins.v3/qqmusicplaylistsync
python .github/scripts/check_plugin_versions.py package.v3.json
python -m pytest -q tests/v3/qqmusicplaylistsync
npm --prefix plugins.v3/qqmusicplaylistsync run check
npm --prefix plugins.v3/qqmusicplaylistsync run build
node --test tests/v3/qqmusicplaylistsync/test_page_ui.mjs
git diff --check
```

前端采用直接编写的 Vue 渲染函数 ESM，无 TypeScript/SFC 编译步骤。`frontend/` 为可维护源码，`build` 先校验模块语法再生成 `dist/assets/`，Vue 由 MP 联邦共享运行时提供，无前端第三方构建依赖。

Python 与页面验证覆盖完整读取、配置默认值、跨平台身份、增量去重、失败隔离、即时搜索、逐文件选曲、状态联动、目录缓存和保守历史清理。纯模块测试使用 `app.plugins.qqmusicplaylistsync.*` 生产模块身份，方法契约隔离宿主运行时，不访问真实账号、数据库或下载器。

网易云读取方式参考“歌单同步工具”的完整成员读取策略，使用官方元数据接口和有界超时，不读取参考插件的登录配置。图标由内置 imagegen 生成，原图随插件分发；界面通过 MP 原生图片缓存入口加载图标。
