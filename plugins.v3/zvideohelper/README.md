# 极影视助手 1.12.0（MoviePilot V3）

定时检查 MoviePilot 本地影视入库目录，为确认缺少可选中文字幕的外语影片、剧集补充外挂字幕。保留手动搜索、选字幕与下载，沿用原有豆瓣观影状态和评分配置。

## 使用

在插件首页完成初始化和网页授权，打开设置中的“定时检查并自动补全中文字幕”。默认每 30 分钟发现新文件、检查变化，并最多尝试为 5 个缺中文字幕的文件补全。失败或无匹配结果的媒体至少间隔一天再尝试。首次使用默认关闭自动下载，可先点“首次全量检查”只建立索引和检查标签。

页面分为“影视库补全”和“手动找字幕”。扫描目录支持在插件设置中配置，每行填写一个 MoviePilot **容器内已有目录的绝对路径**；填写后只读取这些目录，留空则沿用 MoviePilot 媒体目录中的本地电影、电视剧入库目录，不包含音乐和远程存储。页面直接显示路径来源和实际目录。重叠目录会去重；路径无效或暂时不可读时明确报错，保留已有记录，不会回退到其他范围，也不会创建目录。

首次任务会枚举全部影视文件并先标为“待检查”，随后在后台串行检查完整范围，不再受旧版每轮 25 个文件限制。“待确认”表示已经检查但信息不足，与“待检查”区分。页面显示已发现、已检查、待检查数量及实际视频轨道探测次数。停止本次任务会保存已完成结果，下次增量检查会继续未完成部分，插件重启后也能复用已持久保存的结果。

后续任务仍需列目录、比较文件信息以发现新增、删除和变化，但只重新检查视频大小、修改时间、NFO 或对应外挂字幕发生变化的文件。未变化的检查结果从持久缓存复用，不反复运行 ffprobe 或查询 TMDB；瞬时探测失败、TMDB 失败等结果至少间隔一天再重试。可点击“强制重检”忽略文件变化缓存，重新检查当前范围。每个 ffprobe 仅使用一个线程，支持时降低进程优先级，设置探测与超时预算，并在探测之间短暂让出资源；不进行全片转码或 OCR。字幕下载限额与检查范围分开配置，不会为了首次覆盖而大量下载。

影视库填写片名后，可“筛选记录”查看已索引文件，或点击“增量检查此作品”“补全此作品”启动任务。片名在服务端先筛选，再统计状态与分页，不混入其他作品，也不受最近 200 条显示上限影响。状态卡和“待检查”按钮均在同一片名范围筛选；“全部状态”恢复此范围全部记录，“清除筛选”恢复全部作品。定时任务始终处理配置的全部目录，任务范围与当前查看范围分开显示。文件位置可按需展开。

手动搜索分两步：输入影视名称，先从 TMDB 列出可能的电影与剧集，以海报卡片显示片名、原名、年份和简介；海报复用 MoviePilot 原生签名图片缓存，图片不可用时显示占位。选定作品后，插件取得它的 IMDb ID 再查字幕，必要时回退片名并校验作品名称与年份。字幕结果只显示所选作品，不能确认归属的结果不混入列表。无需用户知道 TMDB 或 IMDb ID。可按名称筛选字幕或仅看带中文语言标记的条目；语言标记不代表正文或时间轴已经核实。

电视剧还需选择具体季和集：季、集列表来自 TMDB，包含特别篇，集名辅助辨认；确认后只查所选集。整季包先检查包内文件，结果直接展示该集的字幕文件，并保留来源包名；季集不明、别集和多个集混在一个字幕文件的条目不展示。包内预览短期缓存，切换集时复用；未能检查的包单独提示，不混入结果。

从检查记录点击“为此文件找字幕”时，已有 TMDB ID、季集的目标直接使用该作品和季集身份；更换手动搜索作品会清除上次字幕和 NAS 保存目标，避免错存。选择压缩包后可查看包内文本字幕，再选择两种目的地：

点击“选择字幕”时，当前条目直接显示读取进度；成功后定位到下载区。仅含 TXT 说明、不含文本字幕的资源明确展示实际包内文件与不可下载原因，不再留下空下拉框。下载进度、失败原因和成功文件名均显示在下载按钮旁，选择其他版本会清除上次文件和提示。

- **保存到 NAS 媒体目录**：只列出检查记录中 TMDB 身份相同、电视剧季集相同的文件。确认中文正文后保存为 `视频名.zh.srt` / `.zh.ass` / `.zh.ssa` / `.zh.vtt`，保留语言标记以区分中英文，去掉来源标记 `zvideo`。已有文件不批量改名；英文或无语言标记的原字幕保留。没有对应记录时明确提示先检查该作品，或下载到当前设备。自动补全也使用此位置。
- **下载到当前设备**：交给当前浏览器保存，适用于手机、电脑。浏览器从经过 MoviePilot 认证的接口取文件，不接触字幕服务的原始下载地址。

原视频不改写，同名外挂不覆盖。已确认存在中文字幕的媒体不会再自动下载，也不会通过手动 NAS 保存替换现有字幕；仍可下载到设备比较版本。

## 人工确认

每条检查结果都有“人工确认字幕状态”：可标记“已有中文（含硬字幕）”“确认缺少中文”，或恢复最近一次自动判断。待确认记录也可在此处理；未完成检查的文件需等检查结束。页面保留自动检测结果、人工确认标识和时间，状态统计与筛选使用人工确认后的状态。

标记按当前视频文件持久保存，插件重启、增量与强制扫描、字幕或 NFO 变化均不覆盖；原视频被替换或删除后重新检测。确认已有中文会阻止定时及手动 NAS 保存，仍可下载到当前设备。确认缺少中文可进入正常补全；下载到新的中文字幕后更新为已有中文并清除缺少标记。同名文件仍不覆盖；中文原声、STRM、原盘和无法确定 TMDB 原始语言的文件继续遵守原有自动下载限制。恢复自动判断立即采用缓存的检测结果，需要更新时可强制重检。

## 原始语言与字幕判断

从 NFO 的 TMDB ID 复用 MoviePilot 媒体识别取得 `original_language`，按作品原始语言而非片名文字或制片国家判断。普通话、粤语等中文原声作品跳过自动搜索，手动功能保留。语言缺失、TMDB 不可用时列为待确认，不假定作品是外语片。语言结果按作品缓存，剧集不逐集重复请求 TMDB。

检查同名外挂字幕的语言标记和文本对白，展示实际发现的外挂文件、中文／非中文／语言待确认及判断依据。**已有 SRT 不等于已有中文字幕**：存在非中文 SRT 时仍属于“未发现中文”，页面会明确写出已发现的非中文外挂数量。旧版缺中文与待确认记录会轻量补齐外挂依据，复用已缓存的视频轨道判断，无需重新全库探测。再由 `ffprobe` 检查视频内嵌字幕轨道的语言、标题。无语言标记的内嵌字幕、无法识别语言的图形字幕、无法对应的字幕子目录、探测失败均列为待确认。STRM 和 ISO 不读取远程视频或原盘；蓝光目录不递归扫描。

**“未发现中文”指未发现可选字幕，不代表画面上没有烧录字幕。当前不做 OCR，也无法保证每个发行版本字幕的时间轴完全一致。** 自动选择会校验 IMDb 或片名与年份，电视剧要求明确的季集一致，并排除冲突的加长版／导演剪辑版。下载后检查文本时间戳和中文对白，再次确认媒体未变化且仍缺中文字幕才落盘。不确定的候选留给手动选择。

## 网页授权与续期

原生 `zspace-cli` 独立管理 OAuth、刷新和凭证。本仓库包含适配源码，**不分发原生二进制**。

首次使用时，从自己已有的 `zspace-nas-agent-toolkit v0.1.4` 工具包选择 `bin/zspace-cli-linux-x64` 或 `bin/zspace-cli-linux-arm64`，在插件首页导入。只接受当前 NAS 架构对应的已验证 SHA256，导入目录为插件数据目录下的 `subtitle-cli/zspace-cli`，程序权限为 `0700`。

点击“网页授权”，打开极空间网页完成确认，把网页给出的一次性授权码粘贴到插件的隐藏输入框，点“完成授权”。无需终端。授权码只通过已认证 POST 请求送入原 CLI 的私有隐藏终端，不写入配置、日志、命令参数或环境变量。

日常 access token 临期由原 CLI 自动刷新。刷新失败时停止本轮自动下载，页面提示重新授权，并发送一次 MoviePilot 站内系统消息；重新授权后后续定时任务恢复。不会要求用户提供账号密码。插件不读取、导出或复制凭证文件，专用 `zvideohelper` profile 使用权限收紧的原生文件存储。

## 接口与环境边界

- V3 需要 MoviePilot `>=3.1.6,<4`、Linux 和 `ffprobe`，以及局域网可达的极空间 NAS；未验证云端代理模式。
- 原生 CLI 无源码，适配器只将一个固定的原生只读传输入口转换为固定字幕操作：搜索、包内预览、下载到插件专属临时缓存。原生 CLI 的公共只读扩展仍只允许字幕搜索。
- 中继只监听容器本机随机端口，拒绝额外业务路径和重定向，不记录请求头、正文或凭证。仅插件专用 profile 可使用，操作串行，连接配置在退出时恢复；下次操作先修复上次中断的临时地址。
- 搜索与预览的原始下载定位信息仅短期保存在服务端内存。媒体检查历史不保存凭证或下载地址。所有插件接口要求 MoviePilot 登录认证。
- 在极空间本机的 ZFS 容器挂载中自动识别 NAS 缓存对应路径。其他布局需在设置填写 `subtitle-cli/staging` 在 NAS 上的对应路径；无法识别时明确失败，不改写媒体路径。
- V2 和根目录旧插件保留原样。
